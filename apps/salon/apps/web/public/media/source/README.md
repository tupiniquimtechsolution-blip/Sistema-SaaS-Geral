# Vanessa Braz — Source Media

Mídias importadas da pasta pública do Google Drive fornecida para este projeto.

- `images/`: imagens originais.
- `videos/`: vídeos originais.
- `other/`: outros formatos.
- `media-manifest.json`: inventário com MIME, tamanho, SHA-256 e eventuais falhas.

Os nomes de origem são preservados para rastreabilidade.
