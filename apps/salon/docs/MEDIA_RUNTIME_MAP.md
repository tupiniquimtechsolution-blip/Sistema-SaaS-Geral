## Recomendações

### Para Produção
1. **Migrar mídias para CDN** — Supabase Storage, Cloudinary ou Vercel Blob
2. **Otimizar imagens** — Converter para WebP/AVIF, redimensionar
3. **Lazy loading** — Já implementado, mas verificar performance
4. **Poster para vídeos** — Gerar thumbnails dos vídeos
5. **Cache** — Configurar cache headers para mídias

### Para Manutenção
1. **Não mover originais** — Manter `media/source` intacto
2. **Derivadas em pasta separada** — Usar `media/optimized/`
3. **Atualizar catálogo** — Sempre que adicionar novas mídias, atualizar `src/lib/media.ts`
4. **Revisar seleção** — Periodicamente revisar quais imagens estão em uso
